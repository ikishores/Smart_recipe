# Smart Recipe Generator (Image + Ingredients Based)

A simple and beginner-friendly recipe recommendation system built using Node.js (Express) for the backend and pure HTML, CSS, and JavaScript for the frontend. The app suggests recipes based on typed ingredients or uploaded ingredient images (demo detection). This project is built as part of a Technical Assessment.

---

## 🚀 Working Application URL
Live-https://smart-recipe-ty40.onrender.com/




## 🔥 Features

- Search recipes by typing ingredients  
- Upload an image to auto-detect ingredients (stubbed demo)  
- Filter recipes by diet, difficulty, and cooking time  
- 20 pre-loaded recipes with steps, ingredients & metadata  
- Pure HTML/CSS/JS frontend  
- Express.js REST API backend  
- Easy to run for beginners

## 🧠 Brief Approach 

This project uses a clean and simple architecture to make recipe suggestions based on ingredients. The backend is built using Node.js and Express and serves as a lightweight REST API. All recipes are stored in a structured JSON file, making the system easy to understand and modify. The backend supports queries for filtering recipes by ingredients, cooking time, diet type, and difficulty level. This allows flexible and dynamic search.

The frontend is created using pure HTML, CSS, and vanilla JavaScript to keep it beginner-friendly and framework-free. Users can type ingredients or upload an image. The image detection is implemented as a stub function that simulates ingredient recognition, ensuring the feature works without needing real machine learning APIs. The frontend sends API requests to the backend and dynamically displays matching recipes with details like ingredients, steps, time, and servings.

The project fulfills all assignment requirements, including recipe search, ingredient detection simulation, filtering options, and a clean user interface. The codebase is well-structured, easy to understand, and ready for deployment or future improvements like real AI-based image recognition or database integration.
